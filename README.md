# Digital Twin Visualization Framework

This repository contains tools for evaluating and comparing 3D visualization technologies in digital twin applications. It consists of two main applications that work together to help researchers and developers select and benchmark visualization frameworks.

## Applications

### 1. [Visualization Technique Selection Wizard](./wizard/README.md)

An interactive decision-support tool that helps you select the most appropriate visualization technique for your digital twin application based on requirements like immersion needs, hardware constraints, and user interaction patterns.

[→ View Wizard Documentation](./wizard/README.md)

### 2. [3D Visualization Framework Comparison](./3d-visualization-comparison/README.md)

A comprehensive testing framework that enables performance comparison of different WebGL-based 3D visualization frameworks (Three.js, Babylon.js, PlayCanvas) for digital twin applications. Features real-time performance metrics, automated testing scenarios, and Eclipse Ditto integration.

[→ View Framework Comparison Documentation](./3d-visualization-comparison/README.md)

## Getting Started

1. **Start with the Wizard** to determine your visualization requirements
2. **Use the Framework Comparison** to benchmark and select the best implementation approach

See individual application READMEs for detailed setup instructions.

## Research Context

This framework was developed as part of Master's thesis research on digital twin visualization techniques, focusing on performance characteristics and comparative analysis of different visualization approaches.
